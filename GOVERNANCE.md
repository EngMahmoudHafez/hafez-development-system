# Governance

The project uses a maintainer-led model with transparent design discussion in issues and pull requests.

- Maintainers approve releases, schema changes, provider execution, and security policy.
- Contributors can become maintainers through sustained, high-quality work and responsible review.
- Compatibility and safety take priority over adding providers quickly.
- Breaking schema changes require a migration path and a major version.
- Project-specific preferences must not become universal core policy without evidence across multiple projects.
