# Roadmap

## 0.1 — lifecycle foundation

- inspection, adoption, resume, slice planning, verification, and handoff;
- portable skills and plugin manifests;
- read-only Codex and Claude execution;
- provider and host discovery;
- Laravel and Nuxt/Vue adapters.

## 0.2 — isolated writers

- managed Git worktrees and path reservations;
- base-SHA checks and an integration queue;
- structured result schemas for every provider;
- Kimi and Antigravity execution behind external isolation;
- contract tests for provider argument builders.

## 0.3 — multi-repository products

- repository graph and contract producers/consumers;
- capability matrices spanning API, web, admin, mobile, and deployment;
- pinned OpenAPI and generated-client synchronization;
- umbrella verification profiles.

## 1.0 — public stable release

- clean-session acceptance tests across supported harnesses;
- signed releases, checksums, SBOM, and provenance;
- documented plugin-directory publication;
- stable state schemas and migration tooling.
