# Security policy

Please report vulnerabilities privately through GitHub Security Advisories for the repository. Do not open a public issue for credential exposure, command execution, sandbox escape, prompt injection, unsafe worktree handling, or dependency compromise.

HDS never needs provider credentials in repository state. If a report contains a token, revoke it before sending and redact it from logs.

The supported security-update line is the latest minor release. Maintainers will acknowledge a complete report as soon as practical and coordinate remediation and disclosure with the reporter.
